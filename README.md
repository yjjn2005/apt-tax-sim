# 아파트 양도세 · 맞교환 시뮬레이터

2026 세제개편안(장기보유특별공제 → 장기거주소득공제 개편)을 반영한 1세대 1주택 양도세 시뮬레이터.

## 기능
- **매도시점별 양도세 대시보드**: 2026 / 2027(유예) / 2028(거주6%+보유2%, 한도20억) / 2029~(거주8%, 한도10억) 버튼 선택 → 시점별 세액·상세명세·비교차트
- **교환 실익 분석**: 지금 맞교환(B안) vs 계속 보유 후 2029년 이후 매도(C안) 총부담 비교, 지금 일반매도(A안) 참고 표시
- **손익분기 분석**: 교환가액(시가)별 절감액 곡선과 손익분기점 자동 산출
- 계속 거주 가정 토글, 연간 가격 상승률, 취득세율(85㎡ 기준)·중개보수율 조정

## 주의
개산 시뮬레이션으로 법적·세무적 효력이 없으며, 세제개편안은 국회 통과 과정에서 변경될 수 있습니다.
